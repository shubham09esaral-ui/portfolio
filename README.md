## 🚀 Local Development

To run or preview locally, you can open `index.html` in your browser or serve it with any local static file server:

```bash
# Using Python
python3 -m http.server 3000

# Using Node.js npx
npx serve .
```

Open `http://localhost:3000` to view the website.

## ☁️ Deployment

### 1. Push to GitHub
```bash
git add .
git commit -m "feat: initial commit for Shubham Bhatt portfolio website"
git branch -M main
git remote add origin https://github.com/shubham09esaral-ui/portfolio.git
git push -u origin main
```

### 2. Deploy to Vercel (Recommended)
1. Go to [vercel.com/new](https://vercel.com/new) and log in with your GitHub account.
2. Select and **Import** the `portfolio` repository.
3. Click **Deploy** (no build settings required — it automatically serves as a static site).
4. You will instantly receive your live URL: `https://<your-project-name>.vercel.app`.
